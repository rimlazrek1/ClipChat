# Comment Intelligence Tool — Build Plan

A real website for a non-coder. They paste a YouTube link and instantly see smart analysis of the comments. UI matters for the hackathon. No Streamlit.

---

## Step 1 — pipeline.py (DONE)

Do not edit this file. It exposes these functions for `app.py` to call:

- `get_comments(url, max_comments=200, use_cache=False)` — fetch, clean, embed, and score comments
- `embed_query(text)` — turn a search phrase into an embedding vector
- `extract_video_id(url)` — parse any YouTube URL format into an 11-char video ID

Cache (`comments.pkl`) is only for local development.

---

## Step 2 — Backend (app.py)

Create `app.py` using Flask. It returns JSON only — no HTML from Python.

- `POST /api/comments` — call `get_comments(url, use_cache=False)`. Use `extract_video_id(url)` (imported from `pipeline.py`) as the cache key. Store result in a server-side dict. Never call `fetch_comments` directly.
- `POST /api/search` — call `embed_query(query)`, then cosine similarity against each comment's `embedding`. Return sorted results.
- `POST /api/topics` — KMeans on embeddings. For each cluster:
  - Run `TfidfVectorizer` on the cluster's text. Use top 3 terms as the title (e.g. `audio, sound, volume`). Never show "Cluster 0".
  - Find the centroid (mean embedding). Return the one comment closest to it (cosine distance) as the "Core Message".
- `GET /api/timestamps` — extract all timestamps from comments using regex `r'\b\d{1,2}:\d{2}\b'`. Count mentions per minute mark. Return counts for the bar chart.
- `GET /api/analytics` — return total comments, likes, unique authors, sentiment breakdown, top authors, and comments-per-day.
- Filters (apply in all relevant routes): `sentiment_label`, `likes` (min), `published_at` (date range).
- Smart filter logic (apply as a filter option):
  - **Viewer Questions**: comments containing `?` or starting with how, what, where
  - **Technical Issues**: negative sentiment comments containing audio, cut, link, lag, loud, or fixed

---

## Step 3 — Frontend (templates/ + static/)

Flask serves HTML templates. JS in those templates calls the API routes with `fetch()`.

### File structure
- `templates/index.html` — homepage
- `templates/search.html` — search tab
- `templates/topics.html` — topics tab
- `templates/analytics.html` — analytics tab
- `static/` — CSS, JS, assets

### Pages to build

**Homepage (`index.html`)**
- Input box to paste a YouTube link
- On submit, call `POST /api/comments` and redirect to search or show results inline

**Search (`search.html`)**
- Search bar → calls `/api/search`
- Filter bar: sentiment (positive / neutral / negative), min likes, date range
- Smart filter tabs: All / Viewer Questions / Technical Issues
- Search history saved in `localStorage` (persists after closing the tab, no login)

**Topics (`topics.html`)**
- KMeans topic groups → call `/api/topics`
- Each group shows: TF-IDF title (top 3 terms), Core Message card (centroid comment), then the rest of the comments

**Analytics (`analytics.html`)**
- Summary cards: total comments, total likes, unique authors, positive rate
- Timestamp heatmap: bar chart of comment count per minute mark. Clicking a bar filters the comment list to that minute.
- Sentiment breakdown chart
- Comments-per-day chart
- Top authors list

### General UI rules
- HTML + CSS + Tailwind 
- Fully responsive, mobile-first
- No hardcoded pixel font sizes — use `rem` or `clamp()`
- All interactive elements must have hover, focus-visible, and active states
- PDF download button on search and topics pages to export current results
